# 786 Automotive Spares & Salvage website

## Files
- `index.html` — website content and page structure
- `styles.css` — all styling and responsive layout
- `script.js` — mobile navigation and automatic footer year

## Publish with GitHub Pages
1. Create or open your GitHub repository.
2. Upload these three files into the repository's main/root folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and the `/(root)` folder, then save.
6. Wait for GitHub Pages to publish your website.

Keep the three files together in the same folder. The homepage file must be named `index.html`.
